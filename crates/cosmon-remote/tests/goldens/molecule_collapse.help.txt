`POST /v1/molecules/{id}/collapse`; with --key: `PUT /v1/molecules/{id}/collapse-receipts/{key}` (no fallback)

Usage: cosmon-remote molecule collapse [OPTIONS] --reason <REASON> <ID>

Arguments:
  <ID>  Molecule to collapse

Options:
      --profile <PROFILE>
          Profile name (default: `default_profile` from config.toml, or `$COSMON_REMOTE_PROFILE`)
      --reason <REASON>
          Exact approved reason
      --cause <CAUSE>
          Structured collapse cause
      --json
          Render machine-readable JSON instead of human text where applicable
      --key <KEY>
          Caller-generated idempotency key; uses PUT and never falls back to POST
      --token <TOKEN>
          Bearer JWT (overrides `$COSMON_REMOTE_TOKEN`). When unset and an authenticated call is made, the CLI uses the OIDC credential recorded by `login`, refreshing it silently; run `login` if none is stored
      --expect-status <EXPECT_STATUS>
          Nonterminal status confirmed by the operator [possible values: pending, queued, running, frozen, starved]
      --expect-revision <EXPECT_REVISION>
          Revision returned by molecule get
      --approval-digest <APPROVAL_DIGEST>
          Opaque approval digest (keyed mode only)
      --not-after <NOT_AFTER>
          RFC3339 approval deadline (keyed mode only)
      --account <ACCOUNT>
          Rate-limit account (keyed mode only)
      --kind <KIND>
          Rate-limit currency (keyed mode only)
      --reason-kind <REASON_KIND>
          Operator-facing classification (keyed mode only)
  -h, --help
          Print help
