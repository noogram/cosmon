`POST /v1/molecules/merge` — merge two or more molecules into one synthesis molecule and complete the sources. Every source is checked first: one the tenant cannot reach refuses the whole merge, as `not_found`, and nothing is written

Usage: cosmon-remote molecule merge [OPTIONS] --formula <FORMULA> --reason <REASON> <SOURCES>...

Arguments:
  <SOURCES>...  The molecules to merge (at least two)

Options:
      --formula <FORMULA>            Formula the synthesis molecule is nucleated from
      --profile <PROFILE>            Profile name (default: `default_profile` from config.toml, or `$COSMON_REMOTE_PROFILE`)
      --json                         Render machine-readable JSON instead of human text where applicable
      --reason <REASON>              Why the molecules merge
      --product-kind <PRODUCT_KIND>  Kind of the synthesis molecule (server default: decision)
      --token <TOKEN>                Bearer JWT (overrides `$COSMON_REMOTE_TOKEN`). When unset and an authenticated call is made, the CLI uses the OIDC credential recorded by `login`, refreshing it silently; run `login` if none is stored
  -h, --help                         Print help
