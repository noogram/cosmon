Molecule lifecycle (the §8p frozen surface)

Usage: cosmon-remote molecule [OPTIONS] <COMMAND>

Commands:
  nucleate          `POST /v1/molecules` — create a molecule
  list              `GET /v1/molecules` — ensemble list with optional filters
  get               `GET /v1/molecules/{id}`
  result            `GET /v1/molecules/{id}/result` — fetch the canonical deliverable (synthesis.md / result.md / the lone artifact). Prints the body to stdout (text) or a metadata line (binary); `--json` for the full envelope
  status            `GET /v1/molecules/{id}/status` — status, phase, `updated_at` and whether it is terminal, and nothing else: the cheap read a poller repeats. `wait` is this in a loop. Sends a conditional request when it can, so an unmoved molecule costs a 304 and no body
  session           `GET /v1/molecules/{id}/session` — read the worker's message thread: who said what, in order, with a `waiting` verdict when it looks stuck on an unanswered prompt. Survives the worker, unlike the live `/logs` tail. Read-only — nothing is written into the session
  tackle            `POST /v1/molecules/{id}/tackle` [coûteux]
  run               `POST /v1/molecules/{id}/run` — request the resident drain of the DAG rooted at this molecule. The server decides what to tackle, under the binding's bounds (read them via `quota`); 202 on spawn, lifecycle on the events stream
  done              `POST /v1/molecules/{id}/done` — the harvest door (ADR-176 as amended by issue #51): close this molecule and integrate it where that second authority arises. Carries the full parameter set of `cs done` — `--strategy`, `--force`, the hook waivers — because the requester merging into their own trunk is the operator. `--reason` is mandatory and is never fabricated. Refused unless an operator-sealed grant covers it; 200 with the outcome, never 202
  collapse          `POST /v1/molecules/{id}/collapse`; with --key: `PUT /v1/molecules/{id}/collapse-receipts/{key}` (no fallback)
  collapse-receipt  `GET /v1/molecules/{id}/collapse-receipts/{key}` — look up a durable collapse receipt
  freeze            `POST /v1/molecules/{id}/freeze`
  thaw              `POST /v1/molecules/{id}/freeze` with `state: "active"` — resume a frozen molecule (the legacy `/thaw` route is 410 Gone)
  stuck             `POST /v1/molecules/{id}/stuck`
  evolve            `POST /v1/molecules/{id}/evolve` — advance the molecule past its current formula step. The formula is the one the tenant's project holds for it. A step that declares a shell verification command is refused (501), never passed silently
  resurrect         `POST /v1/molecules/{id}/resurrect` — revive a wrecked (frozen) molecule with a fresh worker. Spawns, so it needs the spawn scope and counts against the same live-worker ceiling as `tackle` [coûteux]
  deps              `GET /v1/molecules/{id}/deps` — blocking, lineage and citation links of a molecule. Cross-galaxy links are listed, not resolved
  prime             `GET /v1/molecules/{id}/prime` — the current step context of a live molecule (what `cs prime` prints). Read-only; a terminal molecule answers `terminal: true` and nothing to prime
  decay             `POST /v1/molecules/{id}/decay` — decay the molecule (idea, issue or deliberation) into one product molecule and complete it. The product copies the source's variables, so there is exactly one
  merge             `POST /v1/molecules/merge` — merge two or more molecules into one synthesis molecule and complete the sources. Every source is checked first: one the tenant cannot reach refuses the whole merge, as `not_found`, and nothing is written
  transform         `POST /v1/molecules/{id}/transform` — change the molecule's kind along an edge of the kind graph (idea → task, task → issue, …); it keeps its identity
  tag               `POST /v1/molecules/{id}/tags`
  help              Print this message or the help of the given subcommand(s)

Options:
      --profile <PROFILE>  Profile name (default: `default_profile` from config.toml, or `$COSMON_REMOTE_PROFILE`)
      --json               Render machine-readable JSON instead of human text where applicable
      --token <TOKEN>      Bearer JWT (overrides `$COSMON_REMOTE_TOKEN`). When unset and an authenticated call is made, the CLI uses the OIDC credential recorded by `login`, refreshing it silently; run `login` if none is stored
  -h, --help               Print help
