D-AVATAR instance lifecycle (drained from cs-thin by the fusion)

Usage: cosmon-remote avatar [OPTIONS] <COMMAND>

Commands:
  status      `GET /v1/avatar/{instance_id}/status` — mould or avatar state
  incarnate   `POST /v1/avatar/{instance_id}/incarnate` — bind moule→avatar
  grant       `POST /v1/avatar/{instance_id}/grant` — bind a canal
  audit       `GET /v1/avatar/{instance_id}/audit` — cicatrice + events
  mould-info  `GET /v1/avatar/{instance_id}/mould-info` — pre-incarnation info
  help        Print this message or the help of the given subcommand(s)

Options:
      --profile <PROFILE>  Profile name (default: `default_profile` from config.toml, or `$COSMON_REMOTE_PROFILE`)
      --json               Render machine-readable JSON instead of human text where applicable
      --token <TOKEN>      Bearer JWT (overrides `$COSMON_REMOTE_TOKEN`). When unset and an authenticated call is made, the CLI uses the OIDC credential recorded by `login`, refreshing it silently; run `login` if none is stored
  -h, --help               Print help
