`POST /v1/molecules/{id}/evolve` — advance the molecule past its current formula step. The formula is the one the tenant's project holds for it. A step that declares a shell verification command is refused (501), never passed silently

Usage: cosmon-remote molecule evolve [OPTIONS] --evidence <EVIDENCE> <ID>

Arguments:
  <ID>  

Options:
      --evidence <EVIDENCE>  Evidence documenting why the current step is complete
      --profile <PROFILE>    Profile name (default: `default_profile` from config.toml, or `$COSMON_REMOTE_PROFILE`)
      --json                 Render machine-readable JSON instead of human text where applicable
      --token <TOKEN>        Bearer JWT (overrides `$COSMON_REMOTE_TOKEN`). When unset and an authenticated call is made, the CLI uses the OIDC credential recorded by `login`, refreshing it silently; run `login` if none is stored
  -h, --help                 Print help
