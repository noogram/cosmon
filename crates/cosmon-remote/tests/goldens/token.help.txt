Print a current access token from the credential saved by `login`.

This writes a bearer to standard output for a program that reads it directly. It deliberately ignores `--token` and `$COSMON_REMOTE_TOKEN`: the saved credential is the one protected by the single-writer refresh path. Pass `--confirm` to acknowledge that stdout may be captured.

Usage: cosmon-remote token [OPTIONS]

Options:
      --confirm
          Acknowledge that the bearer will be written to standard output

      --profile <PROFILE>
          Profile name (default: `default_profile` from config.toml, or `$COSMON_REMOTE_PROFILE`)

      --json
          Render machine-readable JSON instead of human text where applicable

      --token <TOKEN>
          Bearer JWT (overrides `$COSMON_REMOTE_TOKEN`). When unset and an authenticated call is made, the CLI uses the OIDC credential recorded by `login`, refreshing it silently; run `login` if none is stored

  -h, --help
          Print help (see a summary with '-h')
