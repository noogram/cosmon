`POST /v1/molecules/{id}/decay` — decay the molecule (idea, issue or deliberation) into one product molecule and complete it. The product copies the source's variables, so there is exactly one

Usage: cosmon-remote molecule decay [OPTIONS] --formula <FORMULA> --reason <REASON> <ID>

Arguments:
  <ID>  

Options:
      --formula <FORMULA>            Formula the product molecule is nucleated from
      --profile <PROFILE>            Profile name (default: `default_profile` from config.toml, or `$COSMON_REMOTE_PROFILE`)
      --json                         Render machine-readable JSON instead of human text where applicable
      --reason <REASON>              Why the molecule decays
      --product-kind <PRODUCT_KIND>  Kind of the product molecule (server default: task)
      --token <TOKEN>                Bearer JWT (overrides `$COSMON_REMOTE_TOKEN`). When unset and an authenticated call is made, the CLI uses the OIDC credential recorded by `login`, refreshing it silently; run `login` if none is stored
      --blocks <BLOCKS>              A molecule the product blocks. Repeatable
  -h, --help                         Print help
