Send a message to a pilot of the mission, at most 65536 bytes (`POST /v1/pilot/{mission}/messages`)

Usage: cosmon-remote pilot send [OPTIONS] --to <TO> --key <KEY> --message <MESSAGE> <MISSION>

Arguments:
  <MISSION>  

Options:
      --profile <PROFILE>     Profile name (default: `default_profile` from config.toml, or `$COSMON_REMOTE_PROFILE`)
      --to <TO>               Recipient: an attachment or local session piloting the mission
      --json                  Render machine-readable JSON instead of human text where applicable
      --key <KEY>             Keep this key unchanged when retrying a lost response
      --message <MESSAGE>     Message body
      --token <TOKEN>         Bearer JWT (overrides `$COSMON_REMOTE_TOKEN`). When unset and an authenticated call is made, the CLI uses the OIDC credential recorded by `login`, refreshing it silently; run `login` if none is stored
      --expires-in <SECONDS>  Seconds after which an unacknowledged message reads as expired
  -h, --help                  Print help
