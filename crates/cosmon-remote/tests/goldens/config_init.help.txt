Initialise a profile with a host URL if absent. An existing profile, including its login and operator settings, is preserved

Usage: cosmon-remote config init [OPTIONS] <NAME> <HOST>

Arguments:
  <NAME>  Profile name (e.g. `tenant-demo-aws`, `local`)
  <HOST>  Base URL — preserve scheme as-is (`http://…` for loopback, `https://…` for Tailscale-served deployments)

Options:
      --profile <PROFILE>  Profile name (default: `default_profile` from config.toml, or `$COSMON_REMOTE_PROFILE`)
      --report-created     Print only `created` or `preserved` for an installer that applies deployment defaults solely to a newly created profile
      --json               Render machine-readable JSON instead of human text where applicable
      --token <TOKEN>      Bearer JWT (overrides `$COSMON_REMOTE_TOKEN`). When unset and an authenticated call is made, the CLI uses the OIDC credential recorded by `login`, refreshing it silently; run `login` if none is stored
  -h, --help               Print help
