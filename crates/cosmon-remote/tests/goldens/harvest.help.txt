Operator-side remote harvest authority and grants

Usage: cosmon-remote harvest [OPTIONS] <COMMAND>

Commands:
  configure  Compare and set the selected remote policy using the admin credential
  init       Generate an encrypted signer key and install only its public half
  grant      Build, sign and install a grant, or split the workflow into offline steps
  status     Inspect effective policy, provenance, public root and grant validity
  help       Print this message or the help of the given subcommand(s)

Options:
      --profile <PROFILE>  Profile name (default: `default_profile` from config.toml, or `$COSMON_REMOTE_PROFILE`)
      --json               Render machine-readable JSON instead of human text where applicable
      --token <TOKEN>      Bearer JWT (overrides `$COSMON_REMOTE_TOKEN`). When unset and an authenticated call is made, the CLI uses the OIDC credential recorded by `login`, refreshing it silently; run `login` if none is stored
  -h, --help               Print help
